像素画室 v0.10.0 · 中文网页像素编辑器

运行：在此目录运行 npm run dev，打开 http://127.0.0.1:13838/。
线上 HTTPS 地址发布后可在 iPad Safari 打开，分享 → 添加到主屏幕。
首次联网打开并完成缓存后可离线绘画。设备上安装与 Apple Pencil 实测尚未完成。

操作：B 画笔，E 橡皮擦，I 吸管，G 填色，H 移动画布，L 直线，R 矩形。
双指轻点撤销，三指轻点重做；双指拖动、捏合、旋转控制视角。
Ctrl / Cmd + Z 撤销，Shift + Ctrl / Cmd + Z 重做，Space 播放暂停。
默认 Pencil 模式：手指只操作画布，触控笔作画，鼠标仍可绘画。
偏好设置中可开启手指绘画；第二根手指加入时撤回试画，直到所有手指抬起才接受新的笔画。
尺寸、不透明度、吸管与撤销固定在左侧。主工具面板切换时互斥；点击画布先收起，不会同时落笔。面板仍可拖动、收起或关闭。
偏好设置提供智能清晰、平滑预览、原始像素显示。仅改变预览，不改变导出的像素。
新建、重命名、删除使用统一弹窗；面板、弹窗、时间轴带收起动画，并尊重系统减少动态效果设置。
看到新版提示后轻点「保存并更新」，先保存当前作品再切换缓存版本。
Apple Pencil 压力通过 Pointer Events 控制笔刷大小；1px 笔刷保持单像素。
Apple Pencil 硬件双击、挤压快捷动作暂不支持。

作品：IndexedDB 自动保存图层、动画及像素到当前设备的当前浏览器。
浏览器数据被清除、换浏览器、换设备或线上地址变化，都不会自动同步作品。
通过导出 .pixel 项目或 .aseprite 文件备份，再导入即可迁移。
容量：最大 512 × 512，32 图层，240 帧，总计不超过 800 万像素。
撤销最多 30 步，历史像素内存上限约 64 MiB。

文件兼容：
.pixel 保留项目名称、图层、像素、帧时长。
.aseprite 导出标准 32 位 RGBA 普通图层、透明度、可见性、逐帧时长。
Aseprite 导入支持 RGB、灰度、索引色、原始/压缩图像和向前引用已存在帧的链接单元。
分组、特殊混合模式、瓦片、参考图层、独立透明度链接单元、Z 顺序偏移会拒绝导入并说明原因。
索引色转 RGBA。标签、切片、用户附加元数据不保留，会提示。
PNG 当前帧和横向精灵图保留透明度。GIF 输出全部动画帧并循环播放。
GIF 为 216 色近似量化，半透明转换为透明或不透明，精灵图最大宽度 16384。
图片导入仅为单帧图片，GIF / APNG 动画导入尚不支持。

源码是独立网页实现；界面布局参考用户提供的 Pixaki 截图，没有包含 Pixaki 源码或截图中的画作。
雨巷示例由本项目程序绘制。
文件格式依据 Aseprite 官方 docs/ase-file-specs.md。

图片转完美像素（v0.3）：
画廊 → 导入 / 图片转像素，或分享作品 → 导入项目 / Aseprite / 图片转像素。
图片会先进入预览窗口，自动识别像素网格；识别不合适时可指定输出宽高。
支持主色 / 中值 / 中心采样、网格边缘贴合、保留颜色或 16 / 32 / 64 / 128 色调色板。
转换在本地 Web Worker 内完成，不上传图片，不需要服务器或 API 密钥。
此算法用于整理像素风格图，并不进行 AI 风格重绘。普通插画可用手动尺寸像素化。
分析时将最长边缩小至 1024；转换结果最大 512 × 512。保留透明度。
点击使用转换结果创建新作品；取消不改变当前作品。也可单独下载转换 PNG。
也提供直接导入原图；超过 512 的原图会等比例缩小并明确标注。
算法基于 theAmusing/perfectPixel 0.1.4（MIT），已移植并修改为浏览器实现，授权及差异见 dist/perfect-pixel-LICENSE.txt。

插件工作台（v0.4）：
入口：绘画工具菜单 → 插件工作台，或画室设置 → 插件工作台。
五个内置功能均在本地浏览器运行。Magic Pencil 已并入笔刷库；其他扩展可独立启用 / 停用，先生成预览再应用。修改作品像素、图层和帧后可以撤销。
1. 等距盒子：设置左右边长度、高度、三面颜色、描边与高光，支持线框。可新增图层或新建匹配尺寸作品。
2. 魔法铅笔：入口直接打开笔刷库的「魔法」分类。选择描边笔刷、涂鸦滴落、轮廓描边、着色、去色、HSV 偏移、RGB/HSV 混色、提取、向下采集、涂抹选择/减选等笔刷；可限制到当前调色板，在画布涂画使用。
3. 动画套件：导入 .aseprite / .pixel 的图层与帧范围，合成为新图层；静止、直线、正弦路径；按各图层前 N 帧的最小公倍数组合完整循环。
4. 选区吸附：先用矩形选区或魔法选择笔建立选区，再向外吸附到带偏移的网格；移动、复制或提取选区像素。普通画笔与填色受选区约束。
5. 法线光照：选择颜色/法线图层或导入同尺寸 PNG 法线，设置方向、仰角、环境光、漫反射、镜面高光及遮罩；支持全部动画帧，输出独立图层。

实现范围：
根据公开功能描述独立实现，未包含这五款原插件的 Lua 代码或美术资源，不是官方移植，不支持安装 .aseprite-extension / Lua 包。
原作者链接和差异见 dist/plugin-sources.txt；工作台内也有作者链接。
等距盒子的角点与尺寸定义不保证与原插件逐像素一致。动画标签未保留，可改用帧范围。光照使用固定朝向画布的观察方向。
选区与效果笔刷状态是编辑会话状态，不保存进 .pixel / Aseprite 文件；撤销作品修改会清除选区。
新建匹配尺寸作品会保留原作品在画廊，切回原作品即可；新作品创建不属于像素撤销步骤。
画布工作区与选区（v0.5）：
左侧 ＋ 打开插件列表。点每个插件的 ＋ 固定到左侧；也可拖动 ⠿ 到工具栏。固定入口保存在此浏览器中。再点勾选按钮可移除入口。
点快捷插件只打开该插件的设置浮窗；可拖动标题、收缩或关闭。浮窗不移动画布，也不遮罩画布。画布变化后旧预览失效，避免覆盖新绘制的内容。
选区底部面板：自动（魔棒）、手绘、矩形、椭圆；支持替换、添加、减去、反转、拷贝变换、颜色填充、存储与加载选区、清除。
手绘选区：按住拖出闭合轮廓，抬笔后首尾自动闭合。
魔棒：点画布取样；默认按当前图层的相邻颜色选择。容差、相邻区域及参考可见图层可调整，参数改变后重新计算最近一次取样。关闭相邻区域时选择整层匹配颜色。
框选后点「移动与变换」，或直接拖动矩形选区内部，即可移动。角点缩放、顶部圆柄旋转；等比开关、15° 吸附、水平/垂直翻转、复制变换和数值参数都可用。
「应用变换」才修改像素；「取消变换」恢复进入变换前的选区。切到普通绘画工具会应用当前变换；切帧或图层会取消尚未应用的预览。应用后可以撤销。
变换只操作当前图层当前帧，使用最近邻像素采样，超出画布的部分会裁切。空选区不变换。选区暂不支持羽化、透视扭曲或网格变形。
存储选区在本设备保留一个位置，加载需要画布宽高一致。

长按与形状辅助（v0.5）：
铅笔或橡皮起笔后原地长按约 0.65 秒可取色，试画笔点会撤回，不留下额外像素。继续按住拖动可连续取色。
Pencil 模式下手指也可长按取色，单指滑动仍不作画；双指操作继续控制画布。
用普通铅笔画一条直线或闭合轮廓，停留约 2 秒不移动、不抬笔，可识别直线、矩形、3–8 边形、圆形/椭圆。
识别后不抬笔继续拖动，形状相对起笔点旋转与缩放，抬笔后提交一次笔画，可以撤销。非常潦草或未闭合的轮廓可能无法识别。
此功能为独立几何拟合实现，不保证与 Procreate 完全一致；Apple Pencil 的真实停笔体验尚需 iPad 实机确认。
v0.6 清晰像素、颜色工作室与画廊：
默认使用原始像素硬边显示；旧版显示设置首次更新自动迁移到原始像素。可在画室设置手动选择平滑预览。
PNG 当前帧导出支持 1×、2×、4×、8×，放大采用最近邻采样；保留透明度。
SVG 导出当前帧可见图层的合成结果，以矢量像素块记录颜色与透明度，不嵌入位图；不保留可编辑图层或逐帧动画。
颜色工作室：色环、饱和度/明度方块、HSV/RGB、HEX、前后颜色切换、最近使用、配色建议。
预设雨巷、肤色、森林、粉彩、灰阶；可新建/重命名/删除色板，增删颜色，提取画布常用色，导入导出 JSON / GPL。每个色板最多 256 色，最多 100 个色板。
画廊改为全屏作品缩略图网格，支持选择、复制、重命名、删除、导入、照片和新建画布。此版没有作品堆叠分组。

v0.7 Aseprite 动画兼容：
新增普通图层组导入/导出、层级与可见性、锁定状态、动画标签名称/范围/方向/重复次数/颜色。支持旧版穿透图层组和独立合成图层组。
链接单元按自身坐标与透明度正确展开为独立可编辑像素，导出不再保留链接关系。
带标签的文件默认显示图层帧格：标签范围可重叠分层展示，列为帧号与毫秒，行为图层，实心圆为有像素、空心圆为空白；左右滑动查看更多帧，上下滑动查看更多图层。右侧按钮切换缩略图。
选择标签后点播放，仅播放对应片段；「全部帧」恢复全动画。新建/复制/删除帧会同步调整标签范围。
当前限制：特殊混合模式、瓦片、参考图层、非零 Z 顺序仍需转换；切片、附加用户数据不保留。含图层组时暂不支持层级重排，旧版穿透组透明度不可改。组内像素图层正常编辑；锁定图层可在图层面板解锁。


v0.8 · iPad 绘画与动画更新
1. 智能清晰：默认只在缩放和旋转的像素边界做平滑，放大时保留清晰的像素内部。也可选择平滑预览或原始像素。预览不会改变作品数据、PNG 或像素 SVG。
2. 动画设置 → 帧与单元：编辑帧区间时长，复制、插入空帧、删除、倒序和移动区间；当前像素图层的单元可复制、粘贴、清空。
3. 动画标签：创建或修改名称、范围、颜色、正向/反向/往返/反向往返、重复次数。0 表示循环；往返的每个方向各计一次。支持重叠标签。
4. 图层：新建组、编组、解散、移入/移出组、上下排序、折叠、显示和锁定。组的隐藏和锁定作用于子图层。旧 ASE 直通组保持原作合成方式。
5. 时间轴可切换缩略图/图层帧格；拖动上边缘中间的短柄调整高度。倍速框支持自定义 0.1–8×。预览倍速不改变导出；在动画设置中将倍速写入全部帧时长后，导出也使用新速度，可撤销。播放遵循源文件帧时长，不自动生成补间。
6. 洋葱皮：红色前帧、绿色后帧，只显示变化的像素，叠在当前画面上避免被背景遮挡。动画设置 → 播放中可选择前/后帧、当前图层/全部可见图层、透明度。播放时自动隐藏。
7. 工具、笔刷、色板、图层、动画、设置、导出和插件浮窗可同时打开。拖标题移动，减号收起，叉号单独关闭；点击窗口置顶。窗口内独立滚动，插件应用按钮固定在底部。
8. 选区工具有独立浮窗，可移动、收起。⊞ 恢复自动排列；窄屏会在底部留出工具区。隐藏浮窗保留选区，点顶部选区工具再次打开。选区模式下撤销/重做显示在左下角。
9. 偏好设置 → 停笔识别时间：0.2–3 秒，默认 0.8 秒。铅笔画完后不抬笔停留，识别直线、矩形、多边形、圆/椭圆，继续拖动调整方向与大小。圆形按几何参数计算，形状预览按屏幕刷新合并输入，抬笔保留最后位置。长按取色仍是约 0.65 秒。
10. 应用图标改为紫底白色像素脸，包含 SVG、192 和 512 像素图标。旧主屏幕图标是否自动刷新由系统决定。
更新：联网打开画室，出现“新版画室已准备好”后点“保存并更新”。也可在偏好设置检查版本更新；请先结束笔画并应用/取消变换。
本轮已通过桌面浏览器的 iPad 横竖屏尺寸检查。真实 iPadOS、Apple Pencil 与主屏幕安装仍需设备实测。

2026-10-12 · 笔刷库、抖色与四向扩展
点击顶部笔刷按钮或再次点击已选中的铅笔，打开笔刷库。左侧分「像素 / 抖色 / 魔法 / 我的」，右侧显示真实笔触预览。轻点选择，再点同一支笔刷进入调校。
调校分「笔触 / 抖色 / 魔法 / 管理」四页，顶部试画板不影响作品。大小、笔尖形状、8×8 自定义笔尖、压感和效果参数按笔刷单独记忆。
内置 21 支笔刷；右上角 ＋ 或管理页可保存副本到「我的」，最多 48 支。自定义笔刷可重命名、删除，内置笔刷可还原默认参数。笔刷配置只保存在当前浏览器，不包含在作品导出文件中。

抖动绘制：提供 25% / 50% / 75% 和斜线预设，可调点阵密度、纹理格子大小、反转和第二颜色。Bayer 点阵支持 16 档覆盖率。图案固定在画布像素网格，重复涂抹保持相位；关闭双色时保留间隙中的原像素。
选区仍限制绘制范围；橡皮可按相同纹理擦除。魔法效果与抖色组合时，只把前景点阵作为效果范围，不使用第二颜色。
Magic Pencil 的 14 种效果已整合为笔刷；从原插件入口或左侧固定入口也能打开。选区、提取和采集在抬笔后执行。换回普通像素笔刷即可停止魔法效果。

扩展画布：偏好设置 → 扩展画布，或绘画工具菜单 → 扩展画布。上、下、左、右分别输入新增像素，也可一键四周 +8 / +16。蓝框显示新增区域；底部持续显示新尺寸、项目像素内存估算和容量占比。
所有帧、图层一起扩展，已有像素不缩放，新增区域透明。应用后清除当前选区，支持撤销、重做和自动保存。超过 512×512 或 800 万总像素时阻止应用；请先结束笔画或选区变换。
笔刷库的分类、笔触预览和调校流程参考 Procreate 官方手册，未使用其源码或美术资产，也不支持导入 Procreate .brush / .brushset。

v0.9.1 · 自动选区交互
点击顶部魔棒，默认进入「添加」：连续轻点不同区域会累积选区；「移除」扣除区域，「新选区」重新取样。手绘、矩形和椭圆也可配合添加 / 移除细修。
轻点选取后不抬笔，左右拖动即可调整阈值；左减小、右增大，顶部显示百分比。同一次拖动固定取样点，回拖可缩小范围。也可再次按住最近选中的区域调整。
点击「阈值 · 当前层 / 可见层」可使用滑条，开启或关闭相邻限制、切换当前图层 / 所有可见图层，并调节选区外遮罩的浓度。改变取样设置只重算最近一次取样。
选取时以反色与虚线显示选中区域；点击「完成」或画笔，保留选区并在外部显示斜线遮罩，绘画、擦除只影响选区内像素。再次点击正在使用的选区工具可取消选区并返回画笔；叉号只隐藏操作面板。
选区模式下的撤销 / 重做、两指 / 三指轻点只作用于选区操作。添加、移除、清除、反选、加载及一次连续阈值拖动均可撤回；取样点和设置会一同恢复。选区历史最多 30 次 / 4 MiB，包括取样基础遮罩；改动画面像素或切换作品、帧、图层后重置。
第二根手指加入时会撤回当前未结束的选区手势，再开始双指控制画布。选区保持硬边像素；本次未加入羽化或 Procreate 的自动颜色填充模式。

v0.10.0 · 画室工作流
顶部左侧管理作品、设置、工具和选区；右侧为画笔、橡皮、图层、颜色与动画入口。左侧两根滑条控制笔刷大小与不透明度，调整时显示预览。
画笔 / 橡皮：轻点切换，再点打开对应笔刷库；长按未选中的工具约 0.45 秒，将当前笔刷与参数带过去。两者分别记忆每支笔刷的大小、不透明度与纹理，刷新后保留。选择橡皮笔刷不会切回画笔。
同一笔画内反复覆盖保持所设不透明度，抬笔后再画可叠加；橡皮低不透明度按比例擦除。硬边像素和抖色相位保持。Magic 的选区 / 提取类操作不使用不透明度，因此对应滑条禁用。
笔刷工作室：分类在左、参数居中、试画板在右；窄屏调整布局。完成保存并返回笔刷库，取消恢复进入调校前的参数。试画不修改作品；橡皮试画可擦除预览中的笔迹。
图层：轻点选中，再点显示选项；左滑露出锁定 / 复制 / 删除；按住约 0.36 秒后拖动可在同组内排序。复制和排序包含全部动画帧，组会带上子图层，且可撤销。跨组移动保留在图层选项里。
勾选框控制显隐；长按约 0.5 秒独显，再长按恢复此前的显隐状态，包括原本隐藏的图层。N / 百分比按钮打开不透明度和选项。不透明度实时预览，一次拖动记为一次历史。
画廊：点缩略图打开，点作品名重命名；左滑或点省略号显示分享 / 复制 / 删除。选择多个作品后可堆叠；点击堆叠进入，选择作品后可移出。按住拖动排序，拖到已有堆叠上可移入。
作品排序、堆叠名称和成员仅记录作品 ID，保存在本设备；不改变像素或动画，也不包含在 .pixel / .aseprite 导出中。分享导出独立 .pixel 备份；选择多件时浏览器可能要求允许多文件下载。
